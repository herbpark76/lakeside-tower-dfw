## Launch checklist

Before launch, run the sample report to see every piece of placeholder
content the board still needs to replace:

```
npm run sample-report
```

Work through the list with the board. Once the report prints **0 items**,
set `SHOW_SAMPLE_MARKERS` to `false` in `src/data/draft.ts`. This hides all
sample pills and dashed outlines site-wide. Run the report one more time to
confirm, then build and deploy.
